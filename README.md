# fermuarin-tam-cikis-aninda-sikismasi-sanayi-ve-teknoloji-bakanligi
Fermuarın tam çıkış anında sıkışmasını resmi sanayi arızası, milli kumaş güvenliği krizi ve teknoloji standardı sapması sayan; dişi ray, kaydırıcıyı prototip, 'biraz çekince açılır' cümlesini izinsiz müdahale ilan eden Bakanlık. Gerçekten çalışır. Fermuarlar artık tesistir.
